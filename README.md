# WANDERLUST

<p align="center">Wanderlust is a full-stack Airbnb-inspired travel and accommodation platform that allows users to discover, list, and review vacation stays. Built using Node.js, Express.js, MongoDB, and EJS, it features secure user authentication, image uploads with Cloudinary, review management, and a responsive user experience following the MVC architecture.

✨ Highlights

🏡 Create, edit, and manage property listings

🔍 Browse and search available accommodations

👤 Secure authentication and authorization using Passport.js

⭐ Review and rating system

☁️ Cloudinary integration for image uploads

🗄️ MongoDB database with Mongoose ODM

🏗️ MVC architecture with RESTful APIs

🚀 Deployed on Render with GitHub integration

## ✨ Features

- ✅ ✨ Features
- ✅ 🏡 Property Listings
- ✅ - View all available accommodation listings.
- ✅ - Browse detailed information, images, pricing, and location.
- ✅ ➕ Create Listings
- ✅ - Registered users can create and publish new property listings.
- ✅ - Upload property images using Cloudinary.
- ✅ ✏️ Update Listings
- ✅ - Listing owners can edit property details, images, descriptions, and pricing.
- ✅ ❌ Delete Listings
- ✅ - Listing owners can remove their listings from the platform.
- ✅ 👤 User Authentication
- ✅ - Secure user registration and login using Passport.js.
- ✅ - Session-based authentication and authorization.
- ✅ 🔒 Authorization
- ✅ - Only authenticated users can create listings.
- ✅ - Only listing owners can edit or delete their own listings.
- ✅ ⭐ Reviews & Ratings
- ✅ - Users can add reviews and ratings for listed properties.
- ✅ - Review owners can delete their own reviews.
- ✅ 🖼️ Image Management
- ✅ - Cloudinary integration for efficient image upload and storage.
- ✅ 📱 Responsive User Interface
- ✅ - Responsive design for desktop and mobile devices.
- ✅ 🗄️ Database Management
- ✅ - MongoDB with Mongoose for efficient storage and retrieval of users, listings, and reviews.
- ✅ 🏗️ MVC Architecture
- ✅ - Well-structured codebase following the Model-View-Controller (MVC) design pattern.
- ✅ 🚀 Deployment
- ✅ - Deployed on Render with GitHub integration for continuous deployment.
